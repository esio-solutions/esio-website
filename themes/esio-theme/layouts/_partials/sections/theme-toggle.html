{{- /* Theme switcher. Trigger button (palette icon) opens a popover listing one swatch button per theme defined in [params.theme] in hugo.toml. Clicking a swatch sets [data-theme] on via assets/js/shared/theme.js, which also persists the choice to localStorage. Each swatch is a 3-stop gradient built from the theme's resolved surface / primary / surface-container-high so it shows the palette visually rather than just naming it. Theme keys are camelCase in TOML (`modernPro`) but rendered kebab-case in the data-theme attribute (`modern-pro`) — kept in sync with styles.css. */ -}} {{- $colors := site.Params.colors -}} {{- $themes := site.Params.theme -}}
